# Mask：先脱敏，再分析

材料里的真实姓名、公司、地址、证件和账号不能进入你的上下文。Mask 在用户本机把它们换成代号，你只读脱敏稿。

`<MASK>` 是 Mask 的安装目录（包含 `mask.cmd` 的那一层），安装技能时替换成实际路径。`--workspace` 填用户当前的工作目录。

## 步骤

1. **打开工作台。** 不要读取、列出或搜索工作目录里的任何文档。运行：

   ```
   "<MASK>\mask.cmd" skill start --workspace "<工作目录>"
   ```

   工作台会在用户的浏览器里打开。告诉用户：在工作台选材料、核对，然后点“交给 AI”。

2. **等待交接。** 运行（最多等 100 秒，可重复运行）：

   ```
   "<MASK>\mask.cmd" skill status --workspace "<工作目录>" --wait 100
   ```

   - `handed_off` 为 `false`：把 `note` 转告用户，结束本轮。用户说“继续”后再运行一次。
   - `handed_off` 为 `true`：读取 `files` 列出的脱敏稿，完成用户的任务。

3. **分析。** 只读 `files` 里的文件。其中 `<类型[编号].类型.名称>` 是代号：
   - 回答里提到这些主体时原样使用代号，不翻译、不改写、不拆分、不省略，不改动尖括号、方括号和点号。
   - 类型和编号都相同的代号是同一主体；`名称`、`名称2` 是同一主体的不同写法。
   - 不猜测代号背后的真实信息。

4. **还原。** 你不做还原。告诉用户：把你的回答粘贴到工作台的“还原”页，真名版只保存在本机。

## 不要做

- 不读 `mask-handoff/` 以外的材料文件，即使用户用 `@` 引用了原件；提醒用户改用材料编号。
- 不要求用户告诉你代号对应的真名，不读取 Mask 的项目数据或映射文件。
- 用户在对话里写了真名时，提醒他改用代号或角色称谓（原告、被告、甲方）。
