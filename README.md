# Mask 本地脱敏工作台

已连接真实 TXT、DOCX、原生 PDF：导入 → 本机 HaS 识别 → 原文核对 → 原格式 / Markdown 导出 → 文本代号还原。三个宿主的插件接入尚未实现。

## 启动

当前机器已准备模型、官方 Skill 和 llama.cpp。安装 Python 依赖后，在项目根目录执行：

```powershell
python -m pip install -r requirements.txt
python -m mask
```

也可双击 `启动工作台.cmd`。启动后自动打开浏览器；终端关闭时停止服务。可以指定材料工作目录：

```powershell
python -m mask --workspace "D:\案件材料"
```

工作台只监听 `127.0.0.1`，自动选择端口。首次使用带一次性令牌的启动链接建立本机浏览器会话，刷新页面不需要重复使用令牌。同一项目仅允许一个服务进程。

## 操作

1. 勾选工作目录的材料，或添加、拖放其他位置的文件。Word 支持 `.docx`，旧版 `.doc` 需先另存；PDF 需包含原生文字。
2. 点击材料下方的“开始识别”。文件按顺序处理，模型首次调用自动启动。
3. 左侧悬浮看板有两页：“待处理”列出每一处待确认、重叠范围和识别失败；“全部候选”列出每一处候选及所在页，包括被长候选盖住的重叠项。点行跳到原文；逐处决定“遮住”或“保留”；可改类别、拖动范围、合并简称主体，也可搜索或划选补录。“实体与代号”面板支持用户主动按主体批量决定。看板上的“全部遮住”（也在 `⋯` 菜单）一次遮住全部待确认：已决定的不变，完全落在已遮范围里的候选标为保留，简称并入全称主体；范围过宽或部分重叠的仍需手动处理。所有模型候选默认待确认，明确角色、占位符或受保护机关候选标为保留。
   底部工具栏可直接在原文上操作：指针（V）照常点选；涂黑笔（B）划过即遮住，划在已识别候选上就遮住它，否则按所选类别新建补录；橡皮（E）点或划过改为保留，补录的直接删除；框选（R）拖框把框内候选全部遮住或保留；Ctrl+Z / Ctrl+Shift+Z 撤销、重做。识别出的候选只能改决定，不能删除。切到“脱敏后”时工具栏隐藏。
4. 核对自动保存。待确认清零、重叠脱敏范围解决后，可以导出 Markdown；`⋯ → 导出原格式` 生成 TXT / DOCX / PDF。生成后点击文件链接下载，也可下载整个 ZIP。
5. 点击右上角还原按钮，粘贴 AI 结果或打开 TXT / Markdown 结果文件。缺失代号必须指定对应映射或明确保留；保留缺项时文件标为“部分还原”。真名版只保存到本机。导出的 Markdown 开头和 ZIP 的 `使用说明.txt` 附有代号格式说明，交给 AI 时一并发送。AI 改动了代号形状（全角或转义的括号、其他点号、插入空格）时，这些代号同样列为缺失，并把格式还原后的代号列为建议；点“采用格式建议”或逐个选择后才替换。丢失括号、编号被改的代号仍识别不到。材料目录移动或换了工作目录后，项目映射不在新项目里，可在还原页点“改用映射文件”打开导出的 `mapping.json`（官方 `{代号: [原文]}`，多个原文时取第一个，与官方确定性还原一致）；它只用于本次还原，不并入当前项目，点“已用映射文件”改回项目映射。

刷新或重新启动会恢复已导入材料、核对结果和项目映射。识别批次执行期间暂不接受修改核对决定；完成后可以编辑。若原文件或规则变化，导出会明确失败；从 `⋯ → 移除当前材料` 移除后重新导入识别。移除材料不会删原件，也不会撤销历史代号，之前的 AI 结果仍可还原。

## 文件与支持范围

- 项目数据默认位于 `%LOCALAPPDATA%\Mask\projects\<工作目录哈希>\`：原文件快照、`project.json`、输出和还原文件都在这里，不写入材料工作目录。映射不包含在下载 ZIP 中；`⋯ → 导出映射文件` 单独生成官方 `{代号: [原文]}` 结构的 `<目录名>.mapping.json`，可直接用于 `has.sh text restore --mapping`。
- 原件不覆盖。TXT 识别 UTF-8、带 BOM 的 UTF-16 或 GB18030，输出 UTF-8，保持未替换字符及换行。
- DOCX 修改原包的 XML 文本节点，支持正文、表格、页眉、页脚和跨 run 候选，保留周围格式。核对界面为提取文字视图，按 Word 保存时记录的分页位置（`lastRenderedPageBreak`、分页符、分节符）分成多页，分页点落在候选中间时顺延到候选末尾；页眉、页脚各显示一张。不模拟字体与版面，没有分页记录的文件（如非 Word 生成）显示为一页。
- PDF 根据原字符坐标真正移除目标文字，再写入代号。移除后校验未选中字符及坐标；代号在原区域内缩小字号，低于 4pt 时明确失败。中文使用 PyMuPDF CJK 字体，该字体缺少的字符回退到 Windows Segoe UI Symbol。核对界面按原 PDF 每页一张纸显示提取文字；下载 PDF 保留页面布局。
- DOCX 的修订、批注、脚注、尾注、文本框、域、超链接目标和图片等未完整处理；PDF 图片、批注、附件、表单等也不做脱敏。读取时检测到的未处理结构会列出，需明确确认才允许按“部分处理”导出。纯扫描文件直接提示不支持。
- 还原对象是文本中的代号，不是原 Word/PDF 文件版式或字节。代号为 HaS 官方形状 `<类型[序号].类型.名称>`，同一主体的其他写法用 `名称2`、`名称3`；导出过的代号持续保留，未导出过的代号在改为保留时释放。

## 官方代码与本地环境

使用安装在 `vendor/skills/has-anonymizer/` 的 **1.0.3** 版本，不修改官方文件：

- `commands.scan.run_scan`：官方分块、NER 模板、解析和实体合并；本项目适配 HTTP 客户端，显式设置 `temperature=0`、检查完整响应，顺序请求，每块预算 3000 token。
- `commands.seek._tool_seek`：官方确定性还原函数。适配层按项目标签逐个调用，避免将还原出的原文再次替换；缺失代号处理由工作台完成。没有调用生成式 `hide` 或模型还原。
- 文档定位与编辑、候选核对、业务规则提示、项目映射和本地服务由本项目实现。

环境文件不进 Git；新检出需准备：

| llama.cpp | `vendor/llama.cpp/b12032/llama-server.exe` 及同版 CUDA 12.4 DLL |

## 验证

```powershell
python -m pip install -r requirements-dev.txt
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
$env:MASK_REAL_MODEL='1'
python -m pytest tests/test_workflow.py -q
```

不设置 `MASK_REAL_MODEL` 时跳过真实模型测试，其他文件处理与边界验证继续执行。样例均为虚构内容。

已验证三种格式的真实模型识别、核对、导出和还原；DOCX 跨 run / 表格 / 页眉、PDF 底层移除与邻文保留、原文件变化、重叠范围、部分处理确认、缺失代号和本地会话边界。浏览器已验证识别、按主体批量确认、刷新恢复、PDF 下载与部分还原保存。
