# 第三方组件与复用边界

## HaS 官方 Skill

直接导入本地安装的 has-anonymizer 1.0.3，不复制或改写官方函数主体。它是运行依赖，不是本项目原创代码。官方 skill 使用 MIT-0 声明；[版本元数据及文件清单](https://clawhub.ai/api/v1/skills/has-anonymizer/versions/1.0.3)。安装版本由 `_meta.json` 检查。

| 官方文件 | 复用方式 |
| --- | --- |
| `scripts/has_text/commands/scan.py` | 调用 `run_scan`，沿用官方分块、NER 与解析路径 |
| `scripts/has_text/client.py` | 继承 `HaSClient`，复用 token 计数；本地 HTTP 请求增加零温度、认证和完整结束校验 |
| `scripts/has_text/commands/seek.py` | 按单个项目代号调用 `_tool_seek`，防止级联替换 |

`_tool_seek` 是内部接口，因此固定 1.0.3；升级前需验证该函数及 scan 的行为。官方公共 restore 流程只识别 `<类型[编号].分类.属性>`，并可能进入模型还原，因此没有直接调用公共 restore 命令。项目适配层支持 `⟦类别编号⟧`，保持一标签对应一个原始写法，并显式返回未知代号。

官方生成式 `hide`、基于差异提取映射的 Pair、模型还原、图片引擎均未接入。

## 模型与推理运行时

- [HaS_Text_0209_0.6B_Q8 模型](https://huggingface.co/xuanwulab/HaS_Text_0209_0.6B_Q8)：模型卡 Apache-2.0 声明。固定版本及 SHA-256 见根目录 README。
- [llama.cpp](https://github.com/ggml-org/llama.cpp)：MIT；本机使用 b12032 Windows CUDA 12.4 便携包。当前不把二进制与权重纳入仓库分发。

## 文档依赖

- [PyMuPDF](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright)：AGPL / 商业双许可；当前用于本地开发。若将产品以闭源形式分发，需要取得适用商业许可或替换该依赖。
- [lxml](https://lxml.de/): BSD；用于保留 DOCX 原包结构并修改对应文本节点。
- [python-docx](https://python-docx.readthedocs.io/)：MIT；仅用于测试生成和复核 Word 样例，不是生产文件编辑路径。
- PDF 字体使用 PyMuPDF 自带 CJK 字体与本机 Windows Segoe UI Symbol；没有把 Windows 字体复制到项目中。

PDF 删除方式依据 [PyMuPDF redaction API](https://pymupdf.readthedocs.io/en/latest/page.html#Page.apply_redactions)：先标记目标字符区域，应用文字删除并保留图形和图片，再校验剩余字符与坐标，写入标签，非增量保存并清理失效对象。存在未识别图片等内容时，输出明确标为部分处理。
